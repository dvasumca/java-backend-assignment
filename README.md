# Java Backend Assignment

## Overview
This project is a Spring Boot REST API for Employee Management.

## Technologies Used
- Java 21
- Spring Boot 3.5.4
- Spring Data JPA
- MySQL
- Maven
- Swagger OpenAPI
- Logback
- REST APIs

## Features
- CRUD Operations
- Validation
- Exception Handling
- Pagination & Sorting
- Request & Response Logging
- Third Party API Integration
- Swagger Documentation

## Database

Database Name:

```
TESTDB
```

## Run Project

```bash
mvn spring-boot:run
```

## Swagger URL

```
http://localhost:8080/swagger-ui/index.html
```

## APIs

POST /api/employees

GET /api/employees

GET /api/employees/{id}

PUT /api/employees/{id}

DELETE /api/employees/{id}

GET /api/employees/{id}/posts
